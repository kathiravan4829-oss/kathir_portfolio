Files:
- index.html: website content
- style.css: responsive purple/black styling
- script.js: mobile navigation and certificate preview
- assets/: your photos and uploaded certificate screenshots

Preview:
Open index.html in a browser.

Publish for free with GitHub Pages:
1. Sign in or create a GitHub account at https://github.com/
2. Create a new PUBLIC repository named: kathiravan-portfolio
3. Upload all files and folders from this ZIP (keep the assets folder).
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish. The link will look like:
   https://YOUR-GITHUB-USERNAME.github.io/kathiravan-portfolio/

Important:
- The 3 projects are marked as starter concepts, not completed projects.
- Your WhatsApp button opens a chat to the phone number you supplied.
- Check the certificate images before publishing: some uploaded screenshots may show a different person's name or app interface. Replace any incorrect screenshot with the original certificate.
- Date of birth is not shown publicly.
- Review your phone number, email and social links before making the site public.
